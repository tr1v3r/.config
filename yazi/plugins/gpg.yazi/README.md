# gpg.yazi

Yazi 内的签名加密与验签解密插件。

## 使用

- `c e`：签名并加密光标文件或已选文件。
- `c d`：解密并验证一个 `.gpg` 文件。

当前使用两个独立的完整指纹：

```text
recipient: 899318F5A4423B72DF6A166FE4AF5FF89222F261
signer:    C633910E8F351365DEAAF300046263C39890F916
```

## 行为

- 单个普通文件：生成 `<文件名>.gpg`。
- 单个目录：先打包，再生成 `<目录名>.tar.gz.gpg`。
- 多选：只接受同一父目录下的项目，合并为一个可命名的 `.tar.gz.gpg`。
- 新文件始终同时签名和加密；解密时签名者必须匹配配置的完整指纹。
- 双收件人密文可由任一匹配的本机私钥解密，不要求配置的 `recipient` 私钥必须在本机。
- 目标已存在时停止，不覆盖。
- 加密文件安全落盘后才删除原项目；恢复完成后才删除密文。
- 旧的无签名 `.gpg` 仍可解密，但必须在警告框中准确输入 `legacy`。

执行加密或解密前还会要求输入 `y`，因为成功后会用结果替换源文件。

## 依赖

- `gpg`
- `tar`
- 对应公钥
- 加密时可用的签名私钥或智能卡 stub
- 解密时可用的解密私钥或智能卡 stub

冒烟测试使用临时 GPG 主目录和临时测试密钥，不访问真实密钥环：

```sh
./tests/gpg-smoke.sh
```
